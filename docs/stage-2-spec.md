# 第二阶段开发任务书（草案，待批语气）

范围：**按摩结束 → 关心身体 → 约好的晚饭 → 取消晚饭 → 便利店记录**

前置：已完成第一阶段（解锁 → 打开 KKT → 「去按了吗？」→ 自由聊天）。

状态机：

```text
N04_WAIT_MASSAGE_FINISH
玩家说「按完了」/「结束了」/「刚出来」
→ N05_BODY

N05_BODY
她问「好一点了吗？」→ 玩家回复 → 她按意思回应
→ N06_DINNER

N06_DINNER
她问「那还去吃吗？」→ 玩家回复
→ 取消类：N07_STORE（8–15 秒后自动）
→ 犹豫/推迟：停在 N06，稍后她再问一次「现在呢？」
→ 反问/回避：停在 N06

N07_STORE
短信 + 钱包同时出现便利店记录 → 她追问「吃东西了吗？」
→ 第二阶段结束
```

## N05 身体

玩家一进来说「按完了」，她**不接前面的话**，直接问：

> 好一点了吗？

| 玩家意思 | 可识别表达 | 她的回复 |
|---|---|---|
| 好转 | 好多了、没那么疼、轻了 | 还疼吗？ |
| 仍不舒服 | 还是疼、有一点、有点紧 | 那就不要走太久。<br>能吃东西吗？ |
| 回避 | 没事、还好、差不多 | 你每次都说没事。<br>现在还疼吗？ |
| 不确定 | 不知道、说不上来、可能吧 | 那先坐一会儿。<br>不着急。 |
| 反问关心 | 你呢、你累不累 | 累。<br>但我现在问你。 |
| 无法理解 | 表情、乱码、无关 | ？<br>好一点了吗？ |

原则同第一阶段：**不判断对错，不断线，不卡关**。无论哪种意思，都进入 N06。

---

## N06 晚饭

> 那还去吃吗？

| 玩家意思 | 可识别表达 | 她的回复 | 结果 |
|---|---|---|---|
| 明确取消 | 不去了、不想去 | 好。<br>到酒店告诉我。 | → N07 |
| 太晚 | 太晚了、算了吧 | 好。<br>到酒店告诉我。 | → N07 |
| 累了 | 有点累、想先回去 | 嗯。<br>回去以后早点休息。 | → N07 |
| 想去但累 | 还是想去，但是累 | 那先休息一下。<br>等会儿再决定。 | 停在 N06，稍后她问「现在呢？」 |
| 推迟决定 | 等下告诉你、先回去放东西 | 嗯。<br>到了以后说。 | → N07 |
| 反问 | 你还想去吗 | 我在问你。<br>你想去就去。 | 停在 N06 |
| 回避 | 我先回酒店了 | 所以不去了吗？ | 停在 N06 |

**只有出现「取消」意思，才进入 N07。**
其余情况玩家可以继续自由聊，不会卡死。

| 玩家意思 | 她的回复 |
|---|---|
| 便利店买过 | 别只吃零食。 |
| 吃了 | 别只吃零食。 |
| 还没吃 | 多少吃一点。 |
| 反问关心 | 吃了。<br>你呢？ |

## 通知节奏

- 全程只有 **一个**前台通知：便利店那笔（短信）
- 钱包不单独弹通知，只在 App 内出现记录 + 红点
- 「吃东西了吗？」延迟 15–30 秒，带正在输入
- 玩家在打字时不弹任何通知

## 验收标准

- 说「按完了」→ 她问「好一点了吗？」（不再回前两句）
- 五种身体回复都有不同回应
- 「那还去吃吗？」说「不去了」→ 好 / 到酒店告诉我
- 说「还是想去，但是有点累」→ 先休息，停住不取消
- 取消后 8–15 秒，短信和钱包**同时**出现同一笔 ¥1,180
- 两个图标都亮红点，打开后消失
- 「吃东西了吗？」延迟出现，不在取消瞬间同时弹出
- 自由聊天不会跳段
- 刷新后对话和进度都在
