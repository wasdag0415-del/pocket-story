# 纵向切片：解锁 → 「你还想去刚才那个地方吗？」

> 验收标准只有一句：**玩家做完这个动作后，手机里有没有留下看得见的变化。**
> 没有，就还只是文案，不是互动。

## 唯一剧情控制器

同一时间只有一套进度在走：`PocketFlow`。
旧 `JapanStory` 章节系统**只保留页面和资料**，不再推进剧情。
所有软件（KKT / 短信 / 钱包 / 地图 / 提醒事项 / 备忘录 / 日历）都从同一个进度读取状态。

---

## 节点契约

每个节点固定五件事：**看到什么 / 能做什么 / 什么算触发 / 触发后哪个软件变化 / 没做时怎么温和提醒**。

### N01 开场：去按了吗
- 看到：锁屏 → 解锁 → KKT 里组长老师「去按了吗？」
- 能做：自由输入
- 触发：发送任意内容
- 变化：无（仅推进对话）
- 没做：锁屏通知保留红点，不推进

### N02 身体与吃饭
- 看到：她按你的意思回应（好一点了吗 / 还疼吗 / 那还去吃吗）
- 能做：自由输入
- 触发：回答「那还去吃吗」
- 变化：准备进入取消支线
- 没做：无

### N03 取消晚饭 → 便利店
- 看到：她回「好。到酒店告诉我。」
- 能做：什么都不做（等）
- 触发：**自动**，约 8–15 秒后
- 变化：
  - 短信收到「海外用卡通知 · 7-ELEVEN ¥1,180」
  - 钱包出现同一笔记录
  - 两个 App 图标亮红点
- 没做：不读取也继续；打开的人更清楚「她没去约好的店」

### N04 吃东西了吗
- 看到：KKT 她追问「吃东西了吗？」
- 能做：自由输入
- 触发：任意回复
- 变化：她回「别只吃零食。」
- 没做：主线不卡

### N05 回酒店
- 看到：「到酒店了吗？」
- 能做：自由输入
- 触发：任意回复
- 变化：她回「好。早点睡。」
- 没做：主线不卡

### N06 次日大阪
- 看到：日历推送「今日行程 · 11:30 大堂集合 · 移动至大阪」
- 能做：打开日历 / 不打开
- 触发：自动
- 变化：日历红点；日历内 9月23日 显示大阪日程
- 没做：不打开也能继续

### N07 伴舞推荐橘子街
- 看到：KKT 伴舞发来地点卡「橘子街」
- 能做：点「存入地图」
- 触发：点地点卡
- 变化：地图多一个已保存地点；按钮变「✓ 已存入地图」
- 没做：地图里可手动找到（不阻塞）

### N08 分享与否（分支）
- 看到：地图橘子街详情页出现「分享给组长老师」
- 能做：分享 / 只保存
- 触发：点分享
- 变化：
  - 分享 → KKT 出现地点消息 → 她回「今天应该不去了，有点累」
  - 只保存 → 演出后再给一次分享机会
- 没做：演出后会再问

### N09 舞台检查 / 紧绷
- 看到：提醒事项「舞台检查 · 还有45分钟」+ 红点
- 能做：勾选 / 打开备忘录
- 触发：自动（时间到）
- 变化：提醒事项可勾选；备忘录出现她紧绷的记录
- 没做：不勾选也不影响演出推进

### N10 演出结束
- 看到：时间推进，KKT 收到「你还想去刚才那个地方吗？」
- 能做：自由输入（接受 / 担心她累 / 反问 / 拒绝 / 只去一下）
- 触发：任意回复
- 变化：她的回应按意思变化；本阶段结束
- 没做：—

## 四层地基（这轮要补的）

| 层 | 现状 | 要做 |
|---|---|---|
| 唯一控制器 | 新旧两套并存 | 只留 PocketFlow |
| 跨软件联动 | 各 App 读各自的 key | 统一读一个剧情状态 |
| 通知调度 | 已做（队列/间隔/暂停/恢复） | 接到每个节点 |
| 防卡关 | 自由输入已有意图分类 | 二次提示、可错过支线 |

---

## 交付顺序

1. 唯一控制器（停掉旧推进）——已完成一部分
2. 状态统一（一个 key）
3. 逐节点接五件事，一次 2–3 个
4. 每接完一组，完整走一遍再继续
