# Pocket Story · 互动模型 v2（证据组合驱动）

> 状态：设计稿，未改动游戏代码。v1 的「章节门槛」模型作废，以本文为准。

## 1. 三条底层能力（现有代码都没有）

| 能力 | 说明 | 现状 |
|---|---|---|
| 时间截面 | 玩家选定一个日期，所有 App 只显示那天的数据 | 没有，各 App 是静态长列表 |
| 证据三层 | 每条线索有 `发现 / 关联 / 理解` 三种状态 | 只有「读过 / 没读过」 |
| 组合判定 | 某组证据达成 AND/OR 条件，才触发下一层内容 | 没有，只有单点解锁 |

没有这三样，写多少剧情都只是「点开就推进」，做不出你要的推理感。

## 2. 证据图（节点 = 玩家的理解，不是章节）

```
身份确认        [巡演日历] OR [工作人员短信] OR [后台照] OR [KKT成员称呼]   （任 2）
   ↓
过去参照        [八月KKT自然聊天] AND ([欧洲出游公开内容] OR [两份食物/互拍照])
   ↓
福冈变化        [事务化KKT] AND ([未接来电] OR [单人吃饭/单独外出照])
   ↓
外界疑问        （自动）浏览器历史出现 Pann 帖 → 评论区「只是性格不同」（干扰项）
   ↓
大阪同行        [天气:风力/日落] AND [地图:橘子街→海边] AND [相册:时间连续、非自拍]
                兜底：相册 + KKT时间 + IG草稿（任 2 可提示，3 项确认）
   ↓
语气回软        大阪KKT生活化片段（风好大 / 头发 / 帮我拿一下）
   ↓
十月同行        [工作同行组] AND [主动靠近组]  → 才知道「大部分是工作，但确实回温」
                工作：日历共同活动 + 车辆安排 + 集合时间 + KKT「车到了」
                靠近：下班后没停的聊天 + 知道耳机在哪 + 无工作却同址 + 重新发无关照片
   ↓
核心真相        三组中达 2 组解锁争执片段，达 3 组具备真结局资格
                情绪：[活动后状态] / [失眠·情绪搜索] / [未完成备忘录]
                靠近：[多次未接来电] / [想说话就打电话] / [停止追问但仍照顾]
                回避：[只是累了] / [只谈身体不谈悲伤] / [没回拨] / [备忘录里「现在说是不是…」]
   ↓
结局            真：核心真相 3 组 + 济州岛锚点
                悬停：理解关系变化，缺根源 → 「要我过去吗？」画面结束
                表面：只有地点、约饭、公开互动 → 「明天一起吃饭」
```

隐藏锚点（可错过，不影响主线，只加强真结局）：大阪天气 → 海边照片 → 搜索建议「风很大的那天」→ 被隐藏的 IG 粉丝截图 → 2021 济州岛互拍。

## 3. 时间截面：日历是唯一的时间入口

- 日历初始只开放少量日期，其余随证据解锁。
- 点日期 = 切换全局 `timeCursor`，各 App 只读那天：KKT 定位阶段、相册当天照片、天气当天、短信当天、通话当天。
- 好处：不用改界面，只改数据过滤；也不用再做独立时间线页。

需要新增：`date` 字段贯穿所有内容（KKT 消息、照片、通话、短信、浏览记录）。

## 4. KKT 输入框（正史 / 非正史分离）

- 玩家自由输入：标记为非正史，可存进存档当彩蛋，**不改变任何判定**。
- 正史消息：由证据触发自动出现，玩家只能决定什么时候去看，不能替涩琪发言。
- 结局：不是菜单选项，而是按「玩家理解了什么」自动走到三种收尾之一。

## 5. 防卡死（软提示，不弹窗）

停留过久时，只做环境提示：天气图标红点、相册生成「大阪那天」、搜索框出现历史建议、KKT 收到一条不推进剧情的普通消息、日历日期下出现小圆点。
